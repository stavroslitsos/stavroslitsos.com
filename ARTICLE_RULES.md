# Faste regler for fagartikler

Denne filen følger prosjektet via Dropbox og GitHub og skal leses før nye
artikler skrives, publiseres eller sendes som nyhetsbrev. Løpende status og
publiseringskø ligger i `README.md`.

1. Skriv originalt fra bunnen. Eksterne lenker og artikler Stavros sender er
   inspirasjon og temapekere, aldri tekst som skal kopieres eller omskrives
   gjenkjennelig.
2. Bruk én tydelig hovedkilde og normalt 5–9 selvstendig innhentede
   støttekilder fra anerkjente tidsskrifter eller relevante myndighetskilder.
3. Verifiser forfattere, tittel, tidsskrift, årstall, DOI/URL og sentrale tall
   mot PubMed, tidsskriftet eller annen primærkilde. Referanser skal aldri
   gjettes.
4. Bevar faglig balanse. Ikke overselg behandling eller skjul forskning som
   nyanserer Stavros' kliniske ståsted.
5. Der det passer naturlig, belys betydningen av korrekt diagnose og tydelig
   kommunikasjon for etterlevelse, bekymring, forløp og behandlingsresultat.
6. Lag norsk hovedversjon og en egen, idiomatisk engelsk versjon. Bruk samme
   struktur som eksisterende artikler, komplett Article JSON-LD og synlige
   emneord nederst.
7. Kilder skal finnes på siden, men være skjult som standard i
   `<details class="article-sources">` rett før emneordene. Bruk «Kilder» på
   norsk og «Sources» på engelsk.
8. Nye ferdige artikler er skjulte utkast inntil Stavros ber om publisering:
   `noindex, nofollow`, ingen artikkelkort, ingen forsidelenke og ingen URL i
   sitemap. Legg dem inn i publiseringskøen i README.
9. Ved publisering: fjern `noindex`, legg NO+EN-kort på Faglig, oppdater
   forsidens teaser når relevant, legg begge URL-er i sitemap og oppdater
   README. Nyhetsbrev sendes samme dag bare når Stavros har autorisert det.
10. Nyhetsbrev er som standard på norsk. Gjenbruk MailerLite-malen
    «Artikkel-teaser (bilde + tekst + knapp)».
