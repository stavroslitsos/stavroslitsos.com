# Oppstart for Claude – stavroslitsos.com

Les `WEBSITE_GUIDE.md` og `README.md` i sin helhet før arbeid starter. Nyeste
status og aktiv publiseringskø står under «Status – hvor arbeidet ble stoppet
sist» i README.

Les også `ARTICLE_RULES.md` før artikkelarbeid og `IMAGE_RULES.md` før bilde-
eller videoarbeid. README er eneste kilde til løpende prosjektstatus og skal
alltid oppdateres når brukeren avslutter en økt.

Live-siden er https://stavroslitsos.com og bygges fra `main` i
https://github.com/stavroslitsos/stavroslitsos.com.
