# Nettside og publisering

- **Navn:** Nettside og publisering.
- **Hovedprosjekt:** `stavroslitsos.com`.
- **Formål:** Vedlikeholde nettsiden og følge publiseringskøen i README.
- **Avklarte beslutninger:** Live bygges fra `main`. Ferdig, kontrollert arbeid
  committes og pushes automatisk. Nye artikler publiseres etter Stavros sin
  beskjed og innenfor publiseringstakten i README. Nyhetsbrev krever uttrykkelig
  beskjed for den konkrete utsendingen.
- **Relevant kontekst og filer:** Les `AGENTS.md` og hele `README.md` ved
  oppstart. Les også `WEBSITE_GUIDE.md`, `ARTICLE_RULES.md` før artikkelarbeid
  og `IMAGE_RULES.md` før bilde- eller videoarbeid. README er autoritativ for
  status og kø; ikke dupliser køen her.
- **Status:** `WEBSITE_GUIDE.md` er opprettet som masterstandard. Personlig
  bilde- og videomateriale skal først vurderes fra Dropbox-mappen
  `Bilde og Video Content/Kan Brukes` og flyttes til `Er Brukt` først etter at
  det faktisk er satt inn, kontrollert og committet i et innlegg. Detaljkrav
  for personvern, KI-merking, webkopier og video er lagt i `IMAGE_RULES.md`.
  Ingen Dropbox-filer ble flyttet og ingen publisering eller utsending er gjort.
  Den aktive publiseringskøen i README har ti artikler.
- **Neste steg:** Følg prioriteringen i README. Publiser og send nyhetsbrev
  først når Stavros uttrykkelig ber om det for den konkrete artikkelen.
- **Dato:** 2026-10-31.
